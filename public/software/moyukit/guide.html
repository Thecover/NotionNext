tless

对齐查看表格

tless 是 table less 的缩写，用来对齐查看 TSV、VCF、空白分隔表格，并通过 less -S 支持左右滚动宽表。

基本用法

tless file.tsv
tless file.vcf
tless file.vcf.gz
command | tless

参数

参数作用
-H, --header显示以 ## 开头的元信息行
-n N显示前 N 行有效数据；N=0 表示全部
-a, -A, --all显示全部有效数据
-h, --help显示帮助
默认隐藏 ## 元信息行，保留 #CHROM 等列名行，并限制前 100 行非 ## 内容。使用 -a 查看超大文件可能较慢。

nf

快速新建或追加文件

nf 是 new file 的缩写，可以直接在终端中输入内容并写入文件。

nf filename
nf -a filename
参数作用
无参数模式覆盖创建文件
-a追加到已有文件末尾
-h, --help显示帮助

结束输入

EOF

或输入：

eof

rr

快速运行 R 脚本 
rr
rr analysis.R
命令等价于
rrRscript 1.r
rr analysis.RRscript analysis.R
如果当前环境中没有 Rscript，rr 会给出明确提示并退出。

mkcd

创建目录并进入

mkcd 用于递归创建目录，并立即进入该目录。

mkcd DIR

等价于：

mkdir -p -- DIR && cd -- DIR

示例

mkcd analysis/result
mkcd "/data/project/new result"
mkcd -- -test
mkcd 是 Bash 函数，因此可以改变当前 Shell 的工作目录。创建失败时不会执行 cd。

feedgpt / fgt

生成给 GPT 的数据说明

feedgpt 会把表格路径、表头、前几行格式、列名和指定列取值范围整理成 Markdown 文本。fgt 是同一命令的简写。

feedgpt [MODE] FILE [OPTIONS]
fgt [MODE] FILE [OPTIONS]

模式

模式简写作用
auto无自动判断文件类型，默认模式
matrixma矩阵模式，适合 count/TPM 等宽矩阵
metadatame元数据模式，适合样本信息表

参数

参数作用
-r, --rows N展示前 N 行数据，不包括表头，默认 3
-c, --columns N最大展示列数，包括第一列，默认 12
-u, --unique COLS输出指定列的有序非重复值，支持列名或从 1 开始的列号
-l, --max-values N每个唯一值列表最多展示 N 个，默认 30
-A, --all-values展示指定列的全部唯一值
-s, --separator TYPE分隔符：auto、tab、whitespace

常用示例

fgt sample_info.txt
fgt ma all_samples_count_matrix.txt
fgt ma all_samples_count_matrix.txt -r 5 -c 20
fgt me all_sample_info.txt -u Stage,Tissue
fgt me all_sample_info.txt -u 5,3
fgt me all_sample_info.txt -u PigID -l 50
fgt me all_sample_info.txt -u PigID -A
fgt -- -strange-file.txt
复制输出给外部模型前，请先检查是否包含样本名、绝对路径或其他敏感信息。

nodeq / nq

查看节点待运行作业

nodeq 用于查看 Slurm 中 node01 到 node06 的待运行作业。nq 是同一命令的简写。

nodeq
nq
nq node03
nq -u wuying
nq node03 -u wuying
nq -u wuying node03

参数

参数作用
node01 到 node06只显示明确请求该节点的待运行作业
-u USER, --user USER只显示指定用户的待运行作业
-h, --help显示帮助

默认输出

[node01]
[node02]
[node03]
[node04]
[node05]
[node06]
[未指定节点]

每个分组显示：

JOBID  USER  NAME  CPUS  MEM_REQ  WAIT  REASON
默认只查询 PD 待运行作业。CPUS 和 MEM_REQ 是申请量，不是实际使用量。WAIT 来自 Slurm PendingTime，不代表排队名次。
nodeq 使用提交时明确请求的 ReqNodes 归类；不会把 ExcNodes 排除节点或 SchedNodes 预测节点当作请求节点。

Slurm 返回显示

1048576M1T
32000M32000M
150000M150000M

jres

查看 Slurm 作业资源报告

jres 表示 job resources，用于查看一个 Slurm 作业的申请资源、状态、退出信息、CPU 使用和 Slurm 观测到的内存峰值。

jres 24455
jres snp
jres
jres --recent
jres --name 24455
jres -- -strange-name

三种定位方式

命令含义适合场景
jres JOBID直接查看指定 Job ID已经知道明确作业号，最推荐
jres JOBNAME按当前用户最近 90 天内完整同名作业定位只记得作业名，不记得 Job ID
jres列出当前用户最近结束的 10 个作业先扫一眼作业号、结束时间和成功状态
jres --recent同无参数模式，也可写作 --list 或 -l需要显式表达“列最近作业”时使用
jres --name JOBNAME强制把参数当作作业名作业名恰好是纯数字或以特殊字符开头
纯数字、数组元素如 12345_7 会优先当作 Job ID。作业名匹配是完整、区分大小写的字面匹配：test 不匹配 test1、mytest 或 Test。

列表与作业名定位规则

  • 只查询当前登录用户，不自动查询其他用户。
  • 作业名和无参数模式固定查询最近 90 天，不扫描全部历史。
  • 无参数模式只列出最近结束的 10 个作业，不自动打开详情。
  • 只统计已经结束的作业，运行中和排队中的作业不会参与无参数列表或作业名定位。
  • 同名作业优先选 End 时间最近的一个；若结束时间完全相同，再按 JobIDRaw 较大的记录选择。
  • 候选查询会排除 .batch、.extern、.0、.1 等 step 记录。

参与最近列表和作业名定位的结束状态

COMPLETED      FAILED          CANCELLED
TIMEOUT        OUT_OF_MEMORY   NODE_FAIL
PREEMPTED      BOOT_FAIL       DEADLINE
REVOKED        SPECIAL_EXIT

报告内容

区块说明
作业概览Job ID、作业名、状态中文解释、节点、运行时间、退出状态
CPU申请核数、分配核数、已结束作业的平均等效使用核数和利用率
内存申请内存、Slurm 观测峰值、峰值占申请比例
提示记账延迟、运行中数据未最终确定、OOM、观测峰值超过申请值、多任务 MaxRSS 限制等
jres 显示的是 Slurm 记账和采样数据，不是实时 top。内存峰值受服务器约 30 秒采样间隔影响，短时峰值可能遗漏；运行中作业暂不强行计算 CPU 利用率。

moyu

管理命令 
moyu help
moyu version
moyu update
moyu channel
moyu channel status
moyu channel stable
moyu channel dev

查看版本

moyu version

示例：

MoyuKit 0.2.1 (stable)
MoyuKit 0.2.1-dev (dev)

查看通道

moyu channel status

会显示持久化通道、当前 Shell 加载通道、稳定版路径、开发版路径和当前版本。

切换通道

moyu channel stable
moyu channel dev

切换通道会影响未来新开的 SSH/Bash 窗口，不会自动打断当前 Shell。当前窗口若要完全刷新，可以手动执行：

exec bash -l
moyu update 只更新稳定版。当前 Shell 处于开发通道时会拒绝线上稳定版覆盖。

安全和使用建议

  • MoyuKit 是用户级工具箱，不需要 sudo。
  • 默认安装在当前用户自己的目录，不写入 /usr、/etc、/opt 等系统目录。
  • nodeq/nq 只做 Slurm 只读查询。
  • jres 只读取 Slurm 记账和状态信息，不提交、取消或修改作业。
  • feedgpt/fgt 不会上传文件，只生成可复制文本。
  • 在共享服务器上使用时，请注意不要把敏感路径、样本名或未公开数据随意复制到外部平台。
